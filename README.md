# One-Line Pitch for First-Time Builders

A single sentence that invites a friend who has never coded to let an AI agent build their first app idea on [make.fun](https://make.fun/c/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3): just describe the idea in plain words, watch the agent build it, free to try, no code to learn, nothing to lose.

`main.ts` writes that one sentence (183 characters) to `/output/entry.txt`, deterministically, with no network access.

Entry for the bounty [A Day of One-Line Pitches](https://make.fun/c/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) on make.fun.
